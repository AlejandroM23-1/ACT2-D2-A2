# ACT2-ALEJANDRO 
¿Qué se aprendió en el día 1?
Se aprendió a codificar entradas y salidas de código, en este caso se utilizó la validación para seguridad básicas utilizando input. También se aprendió a utilizar getpass para datos sensibles y que no se observen a la hora de que el usuario tipee.

¿Qué se aprendió en el día 2?
Se aprendió sobre lectura y escritura en archivos mediante archivos python, utilizando with open("archivo", "r") para la lectura y cambiando la r por la w para la escritura. Intenté leer un archivo inexistente y enviar un mensaje de error con "FileNotFoundError", también se explicó que son los archivos binarios(archivos con "código basura") y como leerlos y modificarlos.

¿Qué se aprendió en el día 3?
En este día se aprendió a formatear y manipular el texto a nuestro favor, realizando conteos de carácteres con mayúsculas y minúsculas además de poder realizar búsquedas dependiendo de sus tipos:
isdigit(para digitos), islower(para minúsculas), isupper(para mayúsculas) y isalpha(para texto).

Todo esto nos servirá para poder realizar scripts que puedan manipular el texto de archivos y realizar entradas para validar tipeos.
